| Column           | Description                                  |
| ---------------- | -------------------------------------------- |
| transaction_id   | Unique ID for each transaction               |
| transaction_date | Date of purchase                             |
| transaction_time | Time when the transaction occurred           |
| transaction_qty  | Number of items purchased                    |
| store_id         | Store identifier                             |
| store_location   | Store branch/location                        |
| product_id       | Product identifier                           |
| unit_price       | Price per unit                               |
| product_category | Category of Products Sold                    |
| product_type     | Type of Product                              |
| product_detail   | Specific product name or variation           |
